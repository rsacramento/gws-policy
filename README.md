# RS Mailbox CLI

A personal, single-user command-line application for the owner's own Gmail
account. It is built on the open-source Google Workspace CLI
(https://github.com/googleworkspace/cli) and is not distributed to or used by
anyone else.

- Privacy policy: [PRIVACY.md](PRIVACY.md)
- Google Workspace CLI: https://github.com/googleworkspace/cli
